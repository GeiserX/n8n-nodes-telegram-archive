# CLAUDE.md — n8n-nodes-telegram-archive

## Overview
n8n community node for Telegram-Archive, enabling querying of archived Telegram chats, messages, folders, and statistics from a self-hosted Telegram-Archive instance within n8n workflows.

## Tech Stack
- TypeScript
- n8n community node SDK
- Vitest (test framework)
- Node.js (build via `package.json` scripts)

## Development
```bash
npm install
npm run build        # Compile TypeScript
npm run lint         # Lint source
npm test             # Run vitest suite

# Icon generation
node build-icons.cjs
```

## Architecture
- `nodes/` — Node implementations (Chat, Message, Stats, Folder, Archive resources + Trigger)
- `credentials/` — Telegram Archive API credential (URL + optional username/password)
- `tests/` — Vitest test suite
- `docs/` — Documentation and images

## Key Rules
- Authentication is optional (session cookie via `POST /api/login`); leave credentials empty if instance has no auth
- Follow n8n community node conventions for resource/operation patterns
- Polling trigger detects new messages by comparing total message counts
- Package published to npm as `n8n-nodes-telegram-archive`
